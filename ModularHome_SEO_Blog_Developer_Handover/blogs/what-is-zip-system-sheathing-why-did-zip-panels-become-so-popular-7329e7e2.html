What Is ZIP System?

ZIP System is a structural wall and roof sheathing system manufactured by Huber Engineered Woods.

Instead of using:

  • standard OSB sheathing
    PLUS

  • separate house wrap

ZIP combines both into:

one integrated system.

The panels feature:

  • structural sheathing

  • built-in weather-resistant barrier

all in a single product.

The seams are then sealed using specialized ZIP tape to create a tighter weather barrier.

What Makes ZIP Different?

Traditional wall systems usually use:

  1. OSB or plywood sheathing

  2. separate house wrap installed over it

ZIP simplifies this by integrating the weather barrier directly onto the panel itself.

This allows builders to:

  • reduce installation steps

  • speed up dry-in

  • improve air sealing

  • reduce moisture exposure
